# YOLO26 Pi Agent Automation

## Project Overview

This project explores the automation of a complete YOLO26 machine-learning workflow using a Pi AI Agent and a single natural-language instruction.

The objective is to reduce manual work by allowing an autonomous AI agent to manage the machine-learning pipeline, from dataset inspection and preparation to model training, validation, testing, results analysis and PowerPoint generation.

## Project Objectives

- Automate dataset inspection and preparation.
- Check annotations, image quality and dataset structure.
- Configure the Python, PyTorch and YOLO26 environment.
- Train the YOLO26 model.
- Validate and independently test model performance.
- Analyse evaluation metrics and model performance.
- Generate visualisations and performance graphs.
- Automatically generate a professional PowerPoint presentation.
- Organise and document all experimental outputs.

## How to Use

1. Clone or download this repository.
2. Open the project in your Pi AI Agent environment.
3. Make sure your dataset is accessible to the agent.
4. Open `PI_AGENT_PROMPT.md`.
5. Copy the complete prompt and provide it to the Pi AI Agent.
6. Allow the agent to inspect the dataset and execute the workflow.
7. Review the generated model, evaluation results, visualisations and PowerPoint presentation.

## Testing the Project as a New User

Follow these steps to independently test the YOLO26 Pi Agent Automation workflow.

### Step 1: Download the Repository

Download the repository using the green Code button and select Download ZIP.

Alternatively, use:

```bash
git clone https://github.com/wardarafiq565/YOLO26-Pi-Agent-Automation.git
```

Extract the downloaded folder if you used ZIP.

### Step 2: Prepare Your Environment

Make sure you have:
- A working Pi AI Agent environment.
- Python installed.
- Compatible YOLO26, Ultralytics and PyTorch dependencies.
- Access to a suitable dataset.
- Sufficient computational resources.

### Step 3: Prepare Your Dataset

Make sure your dataset contains the required images, annotations and dataset configuration file.

The dataset must be accessible to the Pi AI Agent.

### Step 4: Run the Automation Prompt

1. Open the project folder.
2. Open `PI_AGENT_PROMPT.md`.
3. Copy the complete prompt.
4. Open your Pi AI Agent.
5. Give the agent access to the project folder and dataset.
6. Paste the prompt and start the workflow.
7. Follow any requests for missing information or permissions.

### Step 5: Check the Results

Check whether the agent generates:
- Prepared dataset.
- Trained YOLO26 model.
- Training and validation results.
- Independent testing results.
- Performance metrics and graphs.
- PowerPoint presentation.
- Experiment documentation.

### Step 6: Provide Feedback

Please report whether the setup was successful, whether the workflow completed, what outputs were generated and any errors encountered.

Your feedback will help improve the usability and reproducibility of this project.
